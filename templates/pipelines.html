添加脚本节点

从 ~/.rflow/scripts/ 目录自动扫描，系统将解析脚本注解获取参数和输入输出定义

如何定义输入输出？ 
#' @title 脚本标题
#' @description 脚本描述
#' @input deseq_result table DESeq2结果表
#' @input threshold numeric:0.05 显著性阈值
#' @output volcano_plot pdf 火山图
#' @output deg_heatmap image DEG热图

# 文件类型(通过数据源节点加载):
#   file    - 通用文件
#   table   - 表格(csv/tsv/xls/xlsx)
#   image   - 图片(png/jpg/svg)
#   pdf     - PDF文档
#   rdata   - R数据文件(rds/RData)
# 标量类型(通过固定值节点设置):
#   string  - 文本值
#   numeric - 数值
#   boolean - 布尔值
# 类型后加 :默认值 表示可手动设置(如 numeric:0.05)

# 约定: args[1] 始终是输出目录(系统自动传入)
# args[2] 开始才是 @input 定义的参数
args <- commandArgs(trailingOnly = TRUE)
output_dir <- args[1]       # 系统注入，无需声明
deseq_result <- args[2]     # 第一个 @input
threshold <- as.numeric(args[3])  # 第二个 @input
