# JWT Auth + Multi-User Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace Basic Auth with JWT token authentication, add a `users` table with argon2 password hashing, and admin-managed user registration.

**Architecture:** Users table in PostgreSQL with argon2-hashed passwords. Login endpoint issues JWT tokens (HS256, `jsonwebtoken` crate). Auth extractor validates Bearer tokens. Admin can create/list/delete users via protected endpoints. Casbin policies bind to usernames. Initial admin user seeded from env vars on first startup.

**Tech Stack:** jsonwebtoken 9, argon2 0.5 (already added), uuid, chrono, serde

`crates/api/src/jwt.rs`:

```rust
use chrono::{Duration, Utc};
use jsonwebtoken::{decode, encode, DecodingKey, EncodingKey, Header, Validation};
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize)]
pub struct Claims {
    pub sub: String,
    pub role: String,
    pub exp: i64,
}

fn jwt_secret() -> String {
    std::env::var("JWT_SECRET").unwrap_or_else(|_| "dev-secret-change-me".into())
}

pub fn create_token(username: &str, role: &str) -> Result<String, jsonwebtoken::errors::Error> {
    let claims = Claims {
        sub: username.to_string(),
        role: role.to_string(),
        exp: (Utc::now() + Duration::hours(24)).timestamp(),
    };
    encode(&Header::default(), &claims, &EncodingKey::from_secret(jwt_secret().as_bytes()))
}

pub fn verify_token(token: &str) -> Result<Claims, jsonwebtoken::errors::Error> {
    let data = decode::<Claims>(
        token,
        &DecodingKey::from_secret(jwt_secret().as_bytes()),
        &Validation::default(),
    )?;
    Ok(data.claims)
}
```

`crates/api/src/auth.rs`:

```rust
use axum::{
    extract::FromRequestParts,
    http::{header, request::Parts},
};
use rflow_core::AppError;

use crate::error::ApiError;
use crate::jwt;

#[derive(Clone, Debug)]
pub struct AuthUser {
    pub username: String,
    pub role: String,
}

impl<S> FromRequestParts<S> for AuthUser
where
    S: Send + Sync,
{
    type Rejection = ApiError;

    async fn from_request_parts(parts: &mut Parts, _state: &S) -> Result<Self, Self::Rejection> {
        let header_value = parts
            .headers
            .get(header::AUTHORIZATION)
            .and_then(|v| v.to_str().ok())
            .ok_or(AppError::Unauthorized)?;

        let token = header_value
            .strip_prefix("Bearer ")
            .ok_or(AppError::Unauthorized)?;

        let claims = jwt::verify_token(token).map_err(|_| AppError::Unauthorized)?;

        Ok(AuthUser {
            username: claims.sub,
            role: claims.role,
        })
    }
}
```

**Step 1: Write login handler**

`crates/api/src/routes/auth.rs`:

```rust
use argon2::{Argon2, PasswordHash, PasswordVerifier};
use axum::Json;
use axum::extract::State;
use rflow_core::models::{LoginRequest, LoginResponse};
use rflow_core::AppError;

use crate::error::ApiError;
use crate::jwt;
use crate::state::AppState;

pub async fn login(
    State(state): State<AppState>,
    Json(input): Json<LoginRequest>,
) -> Result<Json<LoginResponse>, ApiError> {
    let user = sqlx::query_as::<_, rflow_core::models::User>(
        "SELECT id, username, password_hash, role, created_at, updated_at FROM users WHERE username = $1",
    )
    .bind(&input.username)
    .fetch_optional(&state.pool)
    .await?
    .ok_or(AppError::Unauthorized)?;

    let parsed_hash = PasswordHash::new(&user.password_hash)
        .map_err(|_| AppError::Internal("invalid hash".into()))?;
    Argon2::default()
        .verify_password(input.password.as_bytes(), &parsed_hash)
        .map_err(|_| AppError::Unauthorized)?;

    let token = jwt::create_token(&user.username, &user.role)
        .map_err(|e| AppError::Internal(e.to_string()))?;

    Ok(Json(LoginResponse { token }))
}
```

**Step 1: Write user CRUD handlers (admin-only)**

`crates/api/src/routes/users.rs`:

```rust
use argon2::{Argon2, PasswordHasher, password_hash::SaltString, password_hash::rand_core::OsRng};
use axum::extract::{Path, State};
use axum::http::StatusCode;
use axum::Json;
use uuid::Uuid;
use rflow_core::models::{CreateUser, User};
use rflow_core::AppError;

use crate::auth::AuthUser;
use crate::error::ApiError;
use crate::state::AppState;

pub async fn create(
    State(state): State<AppState>,
    auth_user: AuthUser,
    Json(input): Json<CreateUser>,
) -> Result<(StatusCode, Json<User>), ApiError> {
    if auth_user.role != "admin" {
        return Err(AppError::Forbidden.into());
    }
    if input.username.trim().is_empty() || input.password.len() < 6 {
        return Err(AppError::Validation("username required, password min 6 chars".into()).into());
    }

    let salt = SaltString::generate(&mut OsRng);
    let hash = Argon2::default()
        .hash_password(input.password.as_bytes(), &salt)
        .map_err(|e| AppError::Internal(e.to_string()))?
        .to_string();

    let user = sqlx::query_as::<_, User>(
        "INSERT INTO users (username, password_hash, role) VALUES ($1, $2, $3) RETURNING id, username, password_hash, role, created_at, updated_at",
    )
    .bind(input.username.trim())
    .bind(&hash)
    .bind(&input.role)
    .fetch_one(&state.pool)
    .await?;

    Ok((StatusCode::CREATED, Json(user)))
}

pub async fn list(
    State(state): State<AppState>,
    auth_user: AuthUser,
) -> Result<Json<Vec<User>>, ApiError> {
    if auth_user.role != "admin" {
        return Err(AppError::Forbidden.into());
    }
    let users = sqlx::query_as::<_, User>(
        "SELECT id, username, password_hash, role, created_at, updated_at FROM users ORDER BY created_at",
    )
    .fetch_all(&state.pool)
    .await?;
    Ok(Json(users))
}

pub async fn delete(
    State(state): State<AppState>,
    auth_user: AuthUser,
    Path(id): Path<Uuid>,
) -> Result<StatusCode, ApiError> {
    if auth_user.role != "admin" {
        return Err(AppError::Forbidden.into());
    }
    let result = sqlx::query("DELETE FROM users WHERE id = $1")
        .bind(id)
        .execute(&state.pool)
        .await?;
    if result.rows_affected() == 0 {
        return Err(AppError::NotFound.into());
    }
    Ok(StatusCode::NO_CONTENT)
}
```

```rust
{
    let mut e = enforcer.write().await;
    let policies = e.get_policy();
    if policies.is_empty() {
        // admin role: full access
        for act in ["GET", "POST", "PATCH", "DELETE"] {
            e.add_policy(vec!["admin".into(), "/api/*".into(), act.into()])
                .await.unwrap();
        }
        // editor role: read + write, no delete users
        for act in ["GET", "POST", "PATCH"] {
            e.add_policy(vec!["editor".into(), "/api/*".into(), act.into()])
                .await.unwrap();
        }
        // viewer role: read only
        e.add_policy(vec!["viewer".into(), "/api/*".into(), "GET".into()])
            .await.unwrap();
        tracing::info!("Seeded default RBAC policies");
    }

    // Assign users to their roles via grouping
    let users: Vec<(String, String)> = sqlx::query_as("SELECT username, role FROM users")
        .fetch_all(&pool)
        .await
        .unwrap();
    for (username, role) in users {
        let _ = e.add_role_for_user(&username, &role, None).await;
    }
}
```

## Notes

- `password_hash` field is `#[serde(skip_serializing)]` so it never leaks in API responses.
- JWT secret defaults to a dev value; production must set `JWT_SECRET` env var.
- Admin seeding only runs when users table is empty (first boot).
- Casbin role assignment happens at startup; when a new user is created via API, the handler should also call `enforcer.add_role_for_user()`.
